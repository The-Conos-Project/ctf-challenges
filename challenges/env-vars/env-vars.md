# Linux Env: Variables

Read settings and flags configured via environment variables.

## Flags

### Flag 1: Retrieve the SECRET_FLAG environment variable.
**Flag:** `flag{env_variable_found}`

**Hints:**
- Run the `env` or `printenv` commands.
- Search for 'SECRET_FLAG'.

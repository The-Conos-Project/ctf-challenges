# 01 · Hidden Start (easy)

**RED-0:** Command Line Basics — listing files, including what is normally invisible.

## Goal

This directory is not empty of secrets. Something `ls` alone will not show is holding a **keyword**.

When you have it:

```bash
./checker '<keyword>'
```

## Hints

1. Dotfiles and directories start with `.`
2. Recurse carefully — one level of “cache” is not the whole story.
3. Read small text files; ignore the obvious decoy in the open.

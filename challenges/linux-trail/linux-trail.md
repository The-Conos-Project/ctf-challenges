# Linux Training Trail

Master Linux fundamentals through 10 progressive challenges in a shared environment.

## Challenges

1. **Linux History: Past Logs** — Inspect past terminal command execution records.
2. **Linux Reading: File Contents** — Read file contents in the terminal using standard utilities.
3. **Linux Env: Variables** — Read settings and flags configured via environment variables.
4. **Linux Listing: Hidden Checks** — Learn to list all files in a directory, including hidden dotfiles.
5. **Linux Find: Deep Search** — Search the directory tree for files matching specific names.
6. **Linux Grep: Searching Logs** — Filter and search log files for specific patterns.
7. **Linux Ports: Local Connection** — Interact with network socket interfaces on the local loopback.
8. **Linux Permissions: Restrictive Execute** — Practice executing files without having directory read access.
9. **Linux Processes: Inspect List** — Inspect running system processes and their command line options.
10. **Linux Tar: Extract Archives** — Decompress tarballs and zip files in the terminal.

Each challenge contains one or more flags. Click on a challenge to view details, hints, and submit flags.

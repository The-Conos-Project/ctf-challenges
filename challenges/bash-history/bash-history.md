# Linux History: Past Logs

Inspect past terminal command execution records.

## Flags

### Flag 1: Find the flag in the command execution history.
**Flag:** `flag{history_repeats_itself}`

**Hints:**
- Check the `.bash_history` file.
- Run the `history` command.

### Flag 2: Find the second flag in history timestamps.
**Flag:** `flag{history_tells_no_lies}`

**Hints:**
- History entries may contain timestamps.
- Inspect `~/.bash_history` carefully.

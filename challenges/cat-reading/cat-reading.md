# Linux Reading: File Contents

Read file contents in the terminal using standard utilities.

## Flags

### Flag 1: Print the contents of the flag file.
**Flag:** `flag{cat_content_revealed}`

**Hints:**
- Use the `cat` command.
- The target file is `flag.txt`.

### Flag 2: Use a pager to read the same file.
**Flag:** `flag{less_is_more}`

**Hints:**
- Try `less flag.txt`.
- Pagers are useful for viewing file contents.
